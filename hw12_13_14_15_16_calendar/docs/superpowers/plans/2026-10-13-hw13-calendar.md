# Homework 13 Calendar API implementation

Goal: implement all HTTP/gRPC operations required by ../../13_README.md, using the existing App and storage.
Design approved by user (go): manual net/http and grpc-go servers, HTTP JSON durations and RFC3339 timestamps, protobuf Timestamp/Duration, six methods per transport, date YYYY-MM-DD plus optional IANA timezone (UTC default), configured ports 8080/50051, transport-specific error mapping.

Constraints: keep Go 1.23; preserve storage/domain independence; caller supplies event ID; keep existing overlap/precision semantics; no authentication or messaging subsystems; no commits.

- [x] Update sample YAML, Makefile, lint dependency allowlists, Docker/tooling and README API examples.
- [x] Verify all tests with -race, build, lint, stable regeneration and live HTTP/gRPC interoperability. Request an independent review and address material findings.

Review focus: invalid Timestamp/Duration and integer overflow; omitted versus zero reminder; ID mismatch in update; consistent calendar windows including DST; error responses never leak DB errors; failure of one listener stops the other; canceled requests respect context.
